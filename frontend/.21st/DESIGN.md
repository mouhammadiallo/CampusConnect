# CampusConnect Design Context

## Product

Campus community platform for UASZ. React, TypeScript, Vite, Tailwind CSS 4, and daisyUI 5.

## Visual direction

- Light, expressive, editorial interface rooted in UASZ campus life.
- Use the requested five-color palette across the product: deep teal (`#002e2c`), ocean blue (`#035e7b`), pale lime (`#eff1c5`), soft lime (`#e3e7af`), and olive (`#a2a77f`).
- Use deep teal and ocean blue for emphasis, pale lime surfaces for readability, and soft lime/olive for supporting accents.
- Use readable system/Inter typography with restrained serif accents on campaign-style headings, rounded cards, and visible keyboard focus.
- Sign-in, registration, and the campus feed use a campus-poster composition with graphic shapes and clear calls to action.
- Desktop navigation wraps so every destination remains visible; mobile navigation stays horizontally scrollable.
- Use responsive Tailwind layout utilities and respect reduced-motion preferences.
- Prefer daisyUI cards, buttons, badges, and form controls for their matching roles.

## Evidence

These choices are grounded in `src/styles.css`; daisyUI 5 is listed in `package.json`.
